# React Learning Projects Hub

This repository is a collection of React projects created while learning frontend development, component design, state management, form handling, API communication, Firebase integration, and UI building.

It acts as a personal learning workspace where multiple small apps and experiments are organized in one place for practice, revision, and portfolio growth.

---

## Why this repository exists

The goal of this project collection is to help practice real-world React concepts in a structured manner. It moves from the fundamentals of setup and components to interactive forms, API usage, database integration, and polished UI work.

The projects included here cover a wide range of topics such as:

- React setup and project structure
- Components and JSX
- State and events
- Controlled and uncontrolled inputs
- Form validation
- API calls and POST requests
- Firebase integration
- Data display and table layouts
- Portfolio and landing page design

## Getting Started

Each project is usually self-contained and can be run independently.

### Prerequisites

Before starting, make sure you have:

- [Node.js](https://nodejs.org/) installed
- npm or yarn available
- A code editor like [VS Code](https://code.visualstudio.com/)

### Run a project

```bash
cd <project-folder>
npm install
npm run dev
```

For older projects created with Create React App, this may be used instead:

```bash
npm start
```

> If the project uses Vite, prefer `npm run dev`. If it uses CRA, `npm start` is commonly the correct command.
