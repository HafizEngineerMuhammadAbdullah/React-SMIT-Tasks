# React Learning Projects

This repository is a collection of beginner-to-intermediate React projects created to practice frontend development, state management, forms, API integration, Firebase, and UI building.

It brings together multiple small applications and experiments in one workspace so the learning journey can be tracked in a single place.

---

## Overview

The workspace contains a wide range of React projects, including:

- React fundamentals and environment setup
- State management and event handling
- Controlled and uncontrolled input handling
- Form validation and submission logic
- API call examples
- Firebase projects and dynamic data handling
- Portfolio and UI-inspired clone projects

```text

  → Form_Handling_PartII
```

This sequence follows a natural progression from setup to UI, state, forms, APIs, data handling, and full project building.

## Getting Started

Each project is self-contained. To run any one of them:

```bash
cd <project-folder>
npm install
npm run dev
```

Some older projects may use:

```bash
npm start
```

If a project was created with Vite, use `npm run dev`. If it was created with CRA, `npm start` is commonly used.

## Prerequisites

Before running the projects, make sure you have:
